# AgentGym-RL (Minimal Pipeline)

This is a minimal version of AgentGym-RL with verl and vllm dependencies removed.

## What's Included

This minimized pipeline focuses on the core utilities without the heavy RL training framework.

## Installation

```bash
pip install -e .
```

## Changes from Original

- Removed verl RL training framework
- Removed vllm dependencies
- Simplified dependencies to core requirements only
- Extracted standalone utilities
